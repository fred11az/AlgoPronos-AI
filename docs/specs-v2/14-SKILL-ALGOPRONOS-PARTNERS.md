Un filleul est considéré comme **validé** uniquement si:

## 🔧 Architecture Technique

### Principes

- **Modulaire**: Ajouter des niveaux sans refonte
- **Événementielle**: Chaque action déclenche des notifications
- **Immuable**: Logs d'audit non modifiables
- **Scalable**: Support 10k+ partenaires

### Entités Principales

```
PARTNER
├─ id (unique)
├─ code (code de parrainage)
├─ ref_link (lien unique)
├─ balance (portefeuille)
├─ status (active/suspended)
└─ created_at

REFERRAL
├─ partner_id (qui invite)
├─ referral_user_id (filleul)
├─ status (pending/validated/rejected)
├─ stage (clicked/visited/inscrit/1xbet/deposit)
└─ commission (montant à créditer)

COMMISSION
├─ partner_id
├─ referral_id
├─ level (1, 2, 3...)
├─ amount (250, 100, 50...)
├─ status (pending/credited/withdrawn)
└─ created_at
```

**Question**: "Comment prévenir les faux comptes?"
**Protection**:
1. KYC 1xBet obligatoire
2. Premier dépôt requis (500+ FCFA)

**Question**: "Le filleul de Marie devrait être le mien!"
**Réponse**: Architecture immuable - Filleul attribué à qui l'a invité en premier
